Abbreviations
IV% = implied volatility (annualized).  DTE = days to expiration.  ATM = at-the-money strike (closest to spot).  Δ (Delta) = directional sensitivity.  Γ (Gamma) = how fast delta changes.  ν (Vega) = sensitivity to IV changes (shown per 1% IV in this table).  Θ (Theta/day) = estimated daily time decay (per share; ×100 ≈ per contract).  C / P = call / put.
High Γ / Med Γ = faster/slower acceleration risk.  Fast Θ / Med Θ = faster/slower carry cost.  High ν / Med ν = higher/lower volatility exposure.  High IV / Low IV = expensive/cheap implied volatility.  Short DTE / Long DTE = nearer/further expiry context.
