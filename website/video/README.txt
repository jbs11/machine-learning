ML Trading Course — Video Files
================================

Drop your .mp4 lesson video files here using this naming convention:

  course-1-1.mp4   (Module 1, Lesson 1)
  course-1-2.mp4   (Module 1, Lesson 2)
  ...
  course-9-10.mp4  (Module 9, Lesson 10)

All 72 lessons:
  Module 1: course-1-1.mp4 through course-1-7.mp4
  Module 2: course-2-1.mp4 through course-2-8.mp4
  Module 3: course-3-1.mp4 through course-3-8.mp4
  Module 4: course-4-1.mp4 through course-4-10.mp4
  Module 5: course-5-1.mp4 through course-5-8.mp4
  Module 6: course-6-1.mp4 through course-6-6.mp4
  Module 7: course-7-1.mp4 through course-7-7.mp4
  Module 8: course-8-1.mp4 through course-8-8.mp4
  Module 9: course-9-1.mp4 through course-9-10.mp4

Once a file is in place, the lesson player shows the video
and the Download button offers the .mp4 file for download.
